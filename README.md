# MNIST Dataset 

## Overview
This project explores the MNIST handwritten digit dataset using Python. It focuses on image preprocessing and applying a Decision Tree Classifier to predict handwritten digits from 0 to 9.

## Dataset
- **Dataset:** MNIST
- **Total Images:** 70,000
- **Image Size:** 28 × 28 pixels
- **Classes:** Digits 0–9
- **Image Type:** Grayscale

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Scikit-learn
- Matplotlib

## Practical Implementation
1. Load the MNIST dataset.
2. Normalize image pixel values.
3. Convert images into 784 numerical features.
4. Train a Decision Tree Classifier.
5. Evaluate model performance.
6. Predict handwritten digits and visualize results.

## Learning Objectives
- Understand image datasets and pixel values.
- Practice data preprocessing.
- Learn classification using a Decision Tree.
- Evaluate predictions using accuracy and a classification report.

## Conclusion
This practical helped me understand the basic Machine Learning workflow, including data loading, preprocessing, model training, evaluation, and prediction.
